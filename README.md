# Game Design Skills GitHub Action

A compact set of agent skills for level critique, economy balancing, quest writing, tuning loops, and playtest synthesis. Packaged as a github action so users can adopt it quickly.

## Why This Exists

Skill repos are hot, but many high-value creative domains are barely seeded.

## One-Day MVP

10 skills, example prompts, before/after transcripts, and evaluation tasks.; action.yml, sample workflow, failing and passing fixture repos.

## What It Does Today

- Loads a small JSON task or project description.
- Checks whether the required fields and examples are present.
- Produces a JSON or Markdown readiness report.
- Ships with tests and a CI workflow so the repo is immediately verifiable.

## Install

```bash
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -e .
```

## Run

```bash
python -m game_design_skills_github_action.cli --input examples/sample_input.json --format markdown
```

## Validate

```bash
python -m unittest discover -s tests
```
